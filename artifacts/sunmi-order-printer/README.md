# تطبيق طابعة چڤن — Expo

## حدود المشروع

جميع التعديلات محصورة داخل هذا المجلد. لم تتغير تطبيقات العميل والمندوب
والداشبورد، ولا مسارات الخادم أو قاعدة البيانات، ولا اسم التطبيق أو معرّفه.
التطبيق بقي على Expo ولم يتحول إلى Capacitor.

## ما يعمل باستخدام الخدمات الحالية

- تسجيل الدخول بحساب الإدارة وحفظ الجلسة عبر cookie الخادم؛ لا تُحفظ كلمة المرور.
- الطلبات الحالية بتبويبات وعدّادات وتفاصيل، والقبول والرفض والتجهيز والتسليم.
- اختيار مدة التحضير وسبب الرفض، مع سجل محلي واضح؛ لا يدعم الخادم إرسال
  هاتين المعلومتين إلى العميل، لذلك لا يُعرض له موعد وهمي.
- الطلبات السابقة، البحث برقم الطلب والتاريخ والحالة، وإعادة الطباعة.
- تعيين المندوب وتغييره لطلبات التوصيل في أي حالة من الخدمة الموجودة،
  حتى الطلبات السابقة، مع تأكيد صريح وسجل محلي. إعادة تعيين طلب منتهٍ أو ملغي
  لا تعيد فتحه، لكنها تعيد تعيين المندوب وتُشعره.
- رسائل العملاء، عداد غير مقروء، وردود سريعة، وتحديث دوري.
- إضافة الأصناف وتعديلها وحذفها، الصور بروابط HTTPS، الأحجام والخيارات،
  ترتيب الأصناف داخل الفئة، وإيقاف صنف أو مجموعة الأصناف المعروضة لفئة.
- جدول أسبوعي حقيقي، فترته الواحدة لكل يوم، من API الحالي.
- مركز أحداث محفوظ على الجهاز للحساب الحالي، ومقروء/غير مقروء.
- مساعدة عبر رقم قابل للإعداد واتساب/اتصال، وشروحات نصية.
- إعدادات محلية للصوت والطباعة ونسخ العميل/المطبخ والورق وإبقاء الشاشة نشطة
  عند توفر الوحدة الأصلية اللازمة.

زر طباعة الفاتورة ثابت أسفل تفاصيل الطلب في جميع تبويباته، وتغيير السائق متاح
لطلبات التوصيل من المكان نفسه. يتكدس الزران عموديًا على الشاشات الأضيق.

تنبيه الطلبات التي تنتظر القبول إلزامي، متكرر، وبمستوى صوت 1.0 داخل المشغل.
تغيير السائق قبل القبول لا يُعد قبولًا ولا يسكت التنبيه. الطلب الملغي أو المنتهي
لا يستمر تنبيهه، ويبقى الصوت إذا كانت هناك طلبات أخرى تنتظر القبول.
لا يستطيع التطبيق تجاوز مستوى صوت الوسائط في Android أو حد السماعة المادي؛
ارفع صوت الوسائط من أزرار الجهاز. تعذر تشغيل الصوت يظهر كتوضيح في شاشة الطلبات.

## الطباعة الأصلية

استخدام مكتبة Sunmi الحالية، وتحميلها عند الطباعة فقط. لا تستخدم طباعة المتصفح.
الجهاز المستهدف هو Sunmi V3 بالطابعة المدمجة.

الفاتورة تشمل الاسم ورقم الطلب والوقت والأصناف والكميات والأسعار والملاحظات
والخصم والتوصيل والإجمالي والدفع والعميل والمندوب عند توفره، وQR لمعرّف الطلب.
لا تُخترع قيمة ضريبة غير موجودة في استجابة الخادم؛ يوضح الإيصال عدم توفر التفصيل.
يمكن اختيار نسخة مطبخ ونسخة عميل وعدد من 1 إلى 5 لكل نوع.

اختيار 58 أو 80 مم يغيّر التنسيق، ولا يغيّر إمكانات الطابعة المادية.
لا تختَر 80 مم على طابعة لا تدعمه. يلزم فحص العربية والورق والـQR على الجهاز
قبل الاعتماد التشغيلي.

الطباعة التلقائية للطلبات قيد التحضير تستخدم سجلًا محليًا لمنع التكرار.
عند فشل الطباعة يظهر حدث، ولا تتكرر المحاولة تلقائيًا بصورة عمياء؛ افحص
الفاتورة والورق ثم استخدم الطباعة اليدوية. نجاح أمر SDK لا يضمن خروج الورق،
ولا يمكن ضمان الطباعة مرة واحدة عبر تعطل الجهاز بين الطباعة وحفظ السجل.

## أمور غير مدعومة دون عمل إضافي وموافقة مستقلة

- لا يوفر الخادم الحالي WebSocket للطابعة؛ المزامنة دورية كل خمس ثوان تقريبًا.
- لا يوجد ضمان استمرار الاتصال والتنبيه بعد تعليق Android للتطبيق في الخلفية.
  إبقاء الشاشة مضاءة ليس بديلًا عن خدمة خلفية أو إشعارات دفع أصلية.
- لا توجد عملية استرداد مالي. تبويب الإلغاءات لا يدّعي تنفيذ استرداد.
- لا توجد فترات متعددة لليوم، أو إغلاق مؤقت محفوظ بالخادم،
  أو إعادة توفر الأصناف في وقت محدد يعمل حتى بعد إغلاق التطبيق.
- إدارة الفئات بالكامل، رفع ملفات الصور، والأرشيف الكامل خارج آخر 100 طلب
  تحتاج استكمال إمكانات الخادم الحالي. لا تعدّل JSON الأسعار دون فهم بنيته.
- الواجهة عربية؛ لم يُضف مفتاح إنجليزية غير مكتمل.
- Bluetooth وESC/POS عبر الشبكة غير مضافين؛ يلزمان محولًا أصليًا واختبار
  الموديل الفعلي إن لم يكن الجهاز Sunmi V3.

## التحقق

من هذا المجلد:

```sh
pnpm run typecheck
node scripts/test-terminal.cjs
```

اختبارات العقود تستخدم بيانات معزولة، ولا تتصل بالإنتاج أو بطابعة فعلية.
فحص Metro لحزمة Android ليس APK ولا يثبت صلاحية الطابعة المادية.
لم تُنشأ APK ولم يُنفّذ EAS من هذا التعديل.

بعد توفير نسخة Android مستقلة من مسار البناء المعتمد، انقل ملف APK إلى الجهاز،
واسمح بالتثبيت من المصدر المستخدم، ثم ثبّته دون تغيير معرّف الحزمة أو التوقيع
إذا كان تحديثًا. سجّل الدخول، أوقف الطباعة التلقائية أولًا، نفّذ اختبار الطابعة،
وتحقق من الفاتورة والعربية والـQR قبل تفعيل الطباعة التلقائية.
